# Dra. Jordana de Fáveri — Clínica de Estética

Site estático em português-BR, preparado para demonstração no GitHub Pages.

## Rodar localmente

Sirva esta pasta com qualquer servidor de arquivos estáticos e abra `index.html`. O projeto não depende de npm, backend ou chave de API.

Serviços específicos, Instagram, WhatsApp, credenciais e integrações comerciais não foram publicados como fatos porque ainda não foram confirmados.

## Limites da demonstração

O simulador e o formulário não transmitem dados. Analytics, LeadPilot, envio de formulário, WhatsApp e domínio real exigem configuração e validação com a clínica. O vídeo e a fotografia de apoio são carregados de URLs públicas e precisam de conferência de licença antes de uma publicação comercial.

## Publicação

Crie um repositório, copie estes arquivos para a raiz, habilite GitHub Pages para a branch principal e substitua os URLs `example.github.io` em `index.html`, `robots.txt` e `sitemap.xml` pelo domínio real. Depois repita a auditoria descrita em `docs/auditoria-72-itens.md`.
