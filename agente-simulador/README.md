# Simulador de agente de atendimento

Experiência independente para demonstrar como um agente de atendimento da GPTMaker pode conversar com pacientes da Clínica Dra. Jordana de Fáveri.

O protótipo responde localmente a perguntas sobre localização, horários, contato, Instagram, primeira conversa, serviços, valores, hormônios bioidênticos, segurança e privacidade. Ele não envia dados e não usa uma API de IA.

Para a implantação real, o próximo passo é substituir o mecanismo local por um endpoint ou widget da GPTMaker, definir a base de conhecimento aprovada pela clínica e conectar os canais oficiais de atendimento.
